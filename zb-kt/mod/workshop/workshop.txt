title=ZabricKotlin
description=[h1]ZabricKotlin[/h1]
description=An unofficial Kotlin runtime for ZombieBuddy, made by Dont39. It is not made by ZombieBuddy's author.
description=It does nothing on its own. Mods written in Kotlin require it; subscribe to it along with them and enable it.
description=
description=[h2]What it does[/h2]
description=[list]
description=[*]The game ships an old Kotlin library (1.4.10) that it does not use itself. When the mod list loads, before the mods that use it, this mod puts Kotlin 2.4.21 in its place for all Java mods. It works the same on every launch, the first one included: no restart needed.
description=[*]Provides kotlinx-coroutines 1.11.0 and kotlinx-serialization-json 1.11.0.
description=[*]Checks that everything works and writes the result to console.txt when the mod list loads: "[ZabricKotlin] ready: ..." or an error "[ZabricKotlin] not ready: ..." with the reason. The mods that use it count on it being ready; if it is not, that error says why.
description=[*]Changes no game files and nothing in your saves.
description=[/list]
description=
description=[h2]Requirements[/h2]
description=[list]
description=[*][url=https://steamcommunity.com/sharedfiles/filedetails/?id=3619862853]ZombieBuddy[/url] 2.3.4 or newer with its Java loader installed (it asks you once to approve this mod's Java code).
description=[*]Zabric, the loader layer for ZombieBuddy mods (also by Dont39): subscribe to it and enable it too.
description=[*]Project Zomboid 42.21
description=[/list]
description=Load order: after ZombieBuddy and Zabric, and before the mods that use it.
description=
description=[h2]For mod authors[/h2]
description=[list]
description=[*]Require Zabric and ZabricKotlin in your mod.info (require), load after ZabricKotlin (loadModAfter), and compile against the same Kotlin and kotlinx versions without bundling them.
description=[*]Your code needs no readiness check: ZabricKotlin installs Kotlin when ZombieBuddy reaches its jar in the mod list, on every launch, which is why you load after it: ZombieBuddy loads every class of your javaPkgName and applies your hooks when it reaches your jar. If installing fails, ZabricKotlin logs an error with the reason.
description=[*]Java code that loads Kotlin before ZombieBuddy reaches ZabricKotlin (a ZombieBuddy PreMain, a Zabric preLaunch entrypoint, or a mod above ZabricKotlin in the mod list) gets the game's 1.4.10 and keeps ZabricKotlin from installing. Code that runs at game start must be plain Java.
description=[*]This mod also ships the zb-kt-utils runtime (com.dont39.pz.zbktutils): feature gating, with each feature as the Zabric hook gate of its hooks, and access widening status through Zabric.
description=[/list]
