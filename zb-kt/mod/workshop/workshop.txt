title=ZombieBuddyKotlin
description=[h1]ZombieBuddyKotlin[/h1]
description=An unofficial Kotlin runtime for ZombieBuddy, made by Dont39. It is not made by ZombieBuddy's author.
description=It does nothing on its own. Mods written in Kotlin require it; subscribe to it along with them and enable it.
description=
description=[h2]What it does[/h2]
description=[list]
description=[*]The game ships an old Kotlin library (1.4.10) that it does not use itself. When the game starts, before any mod runs, this mod puts Kotlin 2.4.21 in its place for all Java mods.
description=[*]Provides kotlinx-coroutines 1.11.0 and kotlinx-serialization-json 1.11.0.
description=[*]Checks that everything works and writes the result to console.txt: "[ZombieBuddyKotlin] ready: ..." or "[ZombieBuddyKotlin] not ready: ..." with the reason. While it is not ready, the mods that use it stay off.
description=[*]Changes no game files and nothing in your saves.
description=[/list]
description=
description=[h2]Requirements[/h2]
description=[list]
description=[*][url=https://steamcommunity.com/sharedfiles/filedetails/?id=3619862853]ZombieBuddy[/url] 2.3.4 or newer with its Java loader installed (it asks you once to approve this mod's Java code).
description=[*]Zabric, the loader layer for ZombieBuddy mods (also by Dont39): subscribe to it and enable it too.
description=[*]Project Zomboid 42.21
description=[/list]
description=Load order: ZombieBuddy, Zabric, then this mod, then the mods that use it.
description=
description=[h2]First launch: restart once[/h2]
description=The Kotlin swap has to happen when the game starts, so ZombieBuddy has to run this mod at game start. On its first launch it registers itself with ZombieBuddy through Zabric, writes "[ZombieBuddyKotlin] not ready: ... restart the game once" and Zabric shows a message listing the mods that need a restart. Restart the game once; from then on it is ready at every start. ZombieBuddy runs it at game start without asking again, also after an update of this mod.
description=
description=[h2]For mod authors[/h2]
description=[list]
description=[*]Require Zabric and ZombieBuddyKotlin in your mod.info (require and loadModAfter), and compile against the same Kotlin and kotlinx versions without bundling them.
description=[*]On a launch where ZombieBuddyKotlin is not ready, ZombieBuddy still loads your mod, calls your Main and applies your patches, on the game's Kotlin 1.4.10. Start your Main with "if (!ZombieBuddyKotlin.isReady()) return" (com.dont39.pz.zbkt) and gate every patch and Lua function the same way. Glue generated by this repo's annotation processor gates itself.
description=[*]ZombieBuddyKotlin runs at game start through Zabric, whatever its place in the mod list; a mod that needs to run at game start itself follows the pattern on Zabric's page.
description=[*]This mod also ships the zb-kt-utils runtime (com.dont39.pz.zbktutils): feature gating, hook checks and access widening status through Zabric.
description=[/list]
