title=Sync Guard
description=[h1]Sync Guard[/h1]
description=Items that show up in a container for you but not for the server, or the other way round, until you relog? In multiplayer the game sometimes drops an update to a container or an item without noticing. This mod notices and repairs it from the server's state. 中文说明在下方。
description=
description=[list]
description=[*]After each server tick, the server tells each player what the containers and items it just sent them should look like; a player whose copy differs gets the server's copy of that container.
description=[*]Opening a container checks it once more.
description=[*]A short note over your character when something was repaired; details in console.txt.
description=[/list]
description=
description=Made for Project Zomboid 42.21. On another game version it does nothing and says so in console.txt until it is updated.
description=

description=[h1]同步守护[/h1]
description=物品在你的容器里有、服务器上却没有（或反过来），重新登录才恢复？多人游戏中，游戏有时会丢掉对容器或物品的更新而不自知。本模组能发现这种情况，并按服务器的状态修复。
description=
description=[list]
description=[*]服务器每次更新后，告诉每位玩家刚发给他的容器和物品应是什么样子；玩家这边不一致时，会收到服务器上该容器的内容。
description=[*]打开容器时再检查一次。
description=[*]修复后会在角色头上短暂提示，详情见 console.txt。
description=[/list]
description=
description=为 Project Zomboid 42.21 制作。在其他游戏版本上本模组不做任何事，并在 console.txt 中说明，直到更新为止。
description=
