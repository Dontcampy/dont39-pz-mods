title=Server Reborn
description=[h1]Server Reborn[/h1]
description=Makes multiplayer servers more reliable and more responsive. Add it to the server's mod list; players get it with the server's mods. 中文说明在下方。
description=
description=[h2]Network sync optimization[/h2]
description=Fixes items that show up in a container for you but not for the server, or the other way round, until you relog. The server checks what each player has and repairs any difference from its own state. A short note over your character tells you when something was repaired.
description=
description=[h2]Server tick rate[/h2]
description=Lets a dedicated server update its world up to 20 times a second instead of 10, so actions, item transfers and zombies respond sooner. Set "Server ticks per second" on the "Server Reborn" sandbox page; 10 is the game's own rate. At 20 the server uses about 20% more CPU, and mods that count ticks run faster.
description=
description=Made for Project Zomboid 42.21. On another game version it turns itself off until it is updated.
description=

description=[h1]服务器重生[/h1]
description=让多人游戏服务器更可靠、响应更快。加入服务器的模组列表即可；玩家加入时会随服务器的模组一起获取。
description=
description=[h2]网络同步优化[/h2]
description=修复物品在你的容器里有、服务器上却没有（或反过来），要重新登录才恢复的问题。服务器会检查每位玩家的容器和物品，发现不一致就按服务器的状态修复，并在角色头上短暂提示。
description=
description=[h2]服务器每秒刻数[/h2]
description=专用服务器每秒最多可更新世界 20 次（游戏自身为 10 次），动作、物品转移和僵尸的响应更快。在沙盒选项的“服务器重生”页设置“服务器每秒刻数”，10 为游戏自身的速率。设为 20 时服务器约多用 20% 的 CPU，按刻计数的模组会变快。
description=
description=为 Project Zomboid 42.21 制作。在其他游戏版本上会自动停用，直到更新为止。
description=
