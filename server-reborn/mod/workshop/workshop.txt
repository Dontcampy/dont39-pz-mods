description=Server-side improvements for multiplayer. Add it to the server's mod list; players get it with the server's mods. 中文说明在下方。
description=
description=[h2]Network sync optimization[/h2]
description=Items that show up in a container for you but not for the server, or the other way round, until you relog? In multiplayer the game sometimes drops an update to a container or an item without noticing. The mod notices and repairs it from the server's state.
description=[list]
description=[*]After each server tick, the server tells each player what the containers and items it just sent them should look like; a player whose copy differs gets the server's copy of that container.
description=[*]Opening a container checks it once more.
description=[*]A short note over your character when something was repaired; details in console.txt.
description=[/list]
description=
description=[h2]Server tick rate[/h2]
description=A dedicated server can update its world up to 20 times a second instead of 10, so item transfers, finished actions and other players' zombies reach players sooner and the map loads faster. The server sets "Server ticks per second" on the "Server Reborn" sandbox page; 10 is the game's own rate. At 20 it uses about 20% more CPU, other mods' per-tick code runs twice as often (mods that count ticks run faster), and thrown objects and trailer item drops run faster on the server.
description=
description=Made for Project Zomboid 42.21. On another game version it does nothing and says so in console.txt until it is updated.
description=

description=[h1]服务器重生[/h1]
description=多人游戏的服务器端改进。加入服务器的模组列表即可；玩家加入时会随服务器的模组一起获取。
description=
description=[h2]网络同步优化[/h2]
description=物品在你的容器里有、服务器上却没有（或反过来），重新登录才恢复？多人游戏中，游戏有时会丢掉对容器或物品的更新而不自知。本模组能发现这种情况，并按服务器的状态修复。
description=[list]
description=[*]服务器每次更新后，告诉每位玩家刚发给他的容器和物品应是什么样子；玩家这边不一致时，会收到服务器上该容器的内容。
description=[*]打开容器时再检查一次。
description=[*]修复后会在角色头上短暂提示，详情见 console.txt。
description=[/list]
description=
description=[h2]服务器每秒刻数[/h2]
description=专用服务器每秒最多可更新世界 20 次（游戏自身为 10 次），物品转移、完成的动作和其他玩家的僵尸更新更早送达，地图也加载得更快。服务器在沙盒选项的“服务器重生”页设置“服务器每秒刻数”，10 为游戏自身的速率。设为 20 时约多用 20% 的 CPU，其他模组的每刻代码执行次数翻倍（按刻计数的模组会变快），服务器上的投掷物和拖车掉落物品也会变快。
description=
description=为 Project Zomboid 42.21 制作。在其他游戏版本上本模组不做任何事，并在 console.txt 中说明，直到更新为止。
description=
