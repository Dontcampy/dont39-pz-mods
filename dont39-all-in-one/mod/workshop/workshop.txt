description=[h2]Requirements[/h2]
description=[list]
description=[*][url=https://steamcommunity.com/sharedfiles/filedetails/?id=3619862853]ZombieBuddy[/url] 2.3.4+ (approve this mod's Java code when asked)
description=[*]Zabric and ZabricKotlin (also by Dont39)
description=[*]Project Zomboid 42.21
description=[/list]
description=Load order: ZombieBuddy, Zabric, ZabricKotlin, Dont39 All-in-One. Restart the game once when the main menu asks: on first launch, and after some Zabric or ZabricKotlin updates.
description=
description=[h2]What it adds[/h2]
description=[list]
description=[*][b]Mod Options sidebar[/b]: a list of mods in Options > Mods to jump to their options.
description=[*][b]Keyboard with an IME on[/b]: keys control the game while an IME (e.g. Chinese Pinyin) is on, and typing in text boxes still works. Windows only.
description=[*][b]Faster loading with many mods[/b]: no error for each animation folder a mod does not have.
description=[*][b]Mod animations on Linux dedicated servers[/b]: animations that extend another file load again.
description=[*][b]TCP and KCP tunnel[/b]: for players whose network drops UDP. The server sets a tunnel port in the sandbox options; players choose the tunnel per server in the server list.
description=[*][b]Joining after a Workshop update[/b]: players whose copy of a Workshop mod is newer than the server's can still join, with the server's version downloaded from the server. The server sets "Mod sync port" in the sandbox options. A mod with Java code needs one game restart, which the game does by itself on Windows.
description=[*][b]Network status icon[/b]: ping and packet loss in the corner in multiplayer. Hover it for details, including which kinds of game data make up what you download.
description=[*][b]Appearance override[/b]: lets other mods draw a worn item hidden or as another item, for every player, without changing the item itself. Nothing changes until a mod uses it.
description=[*][b]Shadow Cat Tactics: Dispatch hide and transmog[/b]: with that mod, hiding or transmogging worn clothing changes only how it looks; the item you wear, its stats and contents stay as they are. Clothing hidden or transmogged before this version becomes the real item again, with the same look, the first time its player loads; this cannot be undone, so server owners: back up the save before the first start with this version. Nothing changes without it.
description=[/list]
