description=[h2]Requirements[/h2]
description=[list]
description=[*][url=https://steamcommunity.com/sharedfiles/filedetails/?id=3619862853]ZombieBuddy[/url] 2.3.4+ (approve this mod's Java code when asked)
description=[*]Zabric and ZabricKotlin (also by Dont39)
description=[*]Project Zomboid 42.21
description=[/list]
description=Load order: ZombieBuddy, Zabric, ZabricKotlin, Dont39 All-in-One. On first launch, restart the game once when the main menu asks.
description=
description=[h2]Mod Options sidebar[/h2]
description=Options > Mods gets a list of mods on the right: click one to jump to its options. Remembers your last pick.
description=
description=[h2]Keyboard controls with an IME on[/h2]
description=With an IME (e.g. Chinese Pinyin) on, keys control the game instead of going into the IME; it comes back while you type in a text box, with its candidates shown at the cursor (windowed mode). Windows only.
description=
description=[h2]Faster loading with many mods[/h2]
description=Skips animation folders that mods do not have, instead of logging an error for each one.
description=
description=[h2]Mod animations on Linux dedicated servers[/h2]
description=Fixes animation files that extend another file failing to load because of lowercased file names.
description=
description=[h2]TCP tunnel[/h2]
description=For players whose network drops UDP: the game connection can run through TCP. Other players keep using UDP.
description=[list]
description=[*]Server: set the sandbox option "TCP tunnel port" (0 = off), restart, and open that TCP port in the firewall. Tunnelled players show as 127.0.0.1, so ban them by name or Steam ID, not IP.
description=[*]Players: enable this mod in the main menu, then fill in "TCP port" when adding or editing the server. If the tunnel does not answer within 2 seconds, you join over UDP.
description=[*]Only for joins by address, not via Steam friends, and not from the server's own machine.
description=[/list]
