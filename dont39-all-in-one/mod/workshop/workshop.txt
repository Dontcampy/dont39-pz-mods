description=[h1]Dont39 All-in-One[/h1]
description=A collection of fixes and tweaks for Build 42. They need no mods besides the requirements below; the one fix for another mod does nothing without that mod.
description=
description=[h2]Requirements[/h2]
description=[list]
description=[*][url=https://steamcommunity.com/sharedfiles/filedetails/?id=3619862853]ZombieBuddy[/url] 2.3.4 or newer with its Java loader installed (it asks you once to approve this mod's Java code).
description=[*]Zabric, the loader layer for ZombieBuddy mods (also by Dont39). It opens up game internals the fixes read, at game start.
description=[*]ZabricKotlin, the Kotlin runtime for ZombieBuddy mods (also by Dont39).
description=[*]Project Zomboid 42.21
description=[/list]
description=Load order: ZombieBuddy, Zabric, ZabricKotlin, then Dont39 All-in-One.
description=On the first launch Zabric registers itself with ZombieBuddy to load at game start, and a message on the main menu asks you to restart the game once. Until then the fixes stay off; console.txt says why.
description=
description=[h2]Mod Options sidebar[/h2]
description=Options > Mods shows every mod's options on one long page. This adds a list of those mods on the right: click a mod to jump to its options. The list highlights the mod you are looking at while you scroll.
description=[list]
description=[*]Remembers the mod you last picked and opens the page there, also after a restart (saved in Zomboid/Lua/Dont39AllInOne_ModOptionsSidebar.txt).
description=[*]Only adds the list; option values, Apply, Accept and Back work as before.
description=[*]If another mod changes that page in a way it does not expect, the page still works, just without the list.
description=[/list]
description=
description=[h2]Keyboard controls with an IME on[/h2]
description=With an input method (IME) such as Chinese Pinyin switched on, your keys go into the IME instead of the game, so movement and hotkeys stop working. This keeps the IME out of the game window, so keys control the game whatever the IME state, and brings it back while you type in a text box (chat, search, names), where it works as before.
description=[list]
description=[*]Windows only; elsewhere it stays idle.
description=[*]The IME keeps the mode (e.g. Chinese or English) you last used in a text box.
description=[*]While you type, the IME's input (e.g. the pinyin) and its candidate list show at the text cursor; without this you type blind. Windowed mode only: in borderless or fullscreen mode the game covers the whole screen, and IMEs such as WeChat IME then hide their windows.
description=[*]Other programs' IME is not affected.
description=[/list]
description=
description=[h2]Faster loading with many mods[/h2]
description=While loading animations the game looks into every mod's media/AnimSets and media/actiongroups folders, also when a mod has none, and writes a full error to the log for each missing one. With a few hundred mods that is hundreds of errors and tens of thousands of log lines, mostly while joining a server, and the loading screen waits for them. This skips the folders that do not exist; mods that have them load their animations as before.
description=
description=[h2]Mod animations on Linux dedicated servers[/h2]
description=On a Linux dedicated server whose Workshop folder is inside the server folder (the usual steamcmd setup), animation files that extend another file fail to load: the game looks for the other file with its path in lowercase, and Linux file names are case-sensitive. The log then fills with FileNotFoundException errors and the server is missing those animations. This makes the game open the file with the name the mod gives. Windows, and players' games, are not affected.
description=
description=[h2]Shadow Cat Tactics: Dispatch error spam in multiplayer (temporary)[/h2]
description=Since its 2026-10-17 update, [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3689462578]Shadow Cat Tactics: Dispatch[/url] makes multiplayer clients log "Object tried to call nil in Flush" on every tick after the first outfit (transmog) change, thousands of times per session, with stutter; waiting outfit updates are then only retried when the next one arrives. Players cannot patch it themselves because servers check the mod's Lua files. This replaces the one broken function while the game runs, without touching the mod's files.
description=[list]
description=[*]It replaces the function only while the mod's code is exactly the broken version. Once the mod's author fixes it, this turns itself off (console.txt says so) and will be removed in a later update.
description=[*]Without Shadow Cat Tactics: Dispatch it does nothing.
description=[/list]
description=
description=[h2]TCP tunnel for players whose network drops UDP[/h2]
description=The game talks to the server over UDP. Some networks lose many UDP packets (often UDP throttling by the provider), which shows as lag, rubber-banding and disconnects. With this, a server can also accept players over TCP: the whole game connection runs through a TCP tunnel, unchanged inside. Everyone else keeps joining over UDP as before, on the same server at the same time.
description=[b]Server owners[/b]
description=[list]
description=[*]Add Dont39 All-in-One (and its requirements) to the server's mods.
description=[*]Set the sandbox option "Dont39 All-in-One > TCP tunnel port" to a free TCP port, e.g. 16300, and restart the server. 0 (the default) keeps the tunnel off. The server console then shows "tcp-tunnel: listening on TCP port ...".
description=[*]Open that TCP port in the firewall and router, as you did for the game's UDP ports. The game's UDP ports stay as they are.
description=[*]Tunnelled players show up as 127.0.0.1 in the server (admin panel, logs). An IP ban (banip) on one of them would ban 127.0.0.1, that is every tunnelled player; ban by user name or Steam ID instead. The console logs each tunnel with the player's real address and the 127.0.0.1 port the game sees.
description=[/list]
description=[b]Players[/b]
description=[list]
description=[*]Enable Dont39 All-in-One in the main menu's mod list: the tunnel is set up before the server's mod list is known.
description=[*]In Join Server, edit the server entry (or add one) and fill in "TCP port" below the port with the port the server owner gives you. Empty means UDP only. It is saved for that address in Zomboid/Lua/Dont39AllInOne_TcpTunnel.txt.
description=[*]When you connect, the game tries the tunnel first for up to 2 seconds; if the server does not answer, it joins over UDP as before (console.txt says why).
description=[*]Works with Steam and non-Steam servers when you join by address. Joins that go through Steam networking by Steam ID are not tunnelled. A game running on the same machine as the server cannot use the tunnel.
description=[/list]
