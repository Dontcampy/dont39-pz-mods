description=[h2]Requirements[/h2]
description=[list]

description=Load order: ZombieBuddy, Zabric, ZabricKotlin, Dont39 All-in-One. On first launch, restart the game once when the main menu asks.
description=
description=[h2]Mod Options sidebar[/h2]
description=Options > Mods gets a list of mods on the right: click one to jump to its options. Remembers your last pick.
description=
description=[h2]Keyboard controls with an IME on[/h2]
description=With an IME (e.g. Chinese Pinyin) on, keys control the game instead of going into the IME; it comes back while you type in a text box, with its candidates shown at the cursor (windowed mode). Windows only.
description=
description=[h2]Faster loading with many mods[/h2]
description=Skips animation folders that mods do not have, instead of logging an error for each one.
description=
description=[h2]Mod animations on Linux dedicated servers[/h2]
description=Fixes animation files that extend another file failing to load because of lowercased file names.
description=
description=[h2]TCP and KCP tunnel[/h2]
description=For players whose network drops UDP or loses packets: the game connection can run through a TCP or KCP tunnel, chosen per server. Other players keep using UDP.
description=[list]
description=[*]Server: set the sandbox option "TCP tunnel port" (a TCP port) and/or "KCP tunnel port" (a UDP port), 0 = off, restart, and open that port in the firewall for the right protocol. The KCP and FEC options below them have recommended defaults; players get them when they join.
description=[*]Players: enable this mod in the main menu, then pick "Tunnel:" (Off, TCP or KCP) and "Tunnel port:" when adding or editing the server. The server list shows the tunnel next to the address.
description=[*]No fallback to UDP: if the tunnel does not open, the join stops and shows why. Choose Off to join over UDP.
description=[*]KCP recovers lost packets faster than TCP, but with FEC it can roughly double the bandwidth.
description=[*]Tunnelled players show as 127.0.0.1, so ban them by name or Steam ID, not IP.
description=[*]Only for joins by address, not via Steam friends, and not from the server's own machine.
description=[/list]
description=
description=[h2]Joining after a Workshop update[/h2]
description=When a Workshop mod is updated while a server runs, players who already have the new version cannot join ("Workshop item version is different than the server's"). With this on both sides, they join anyway and play with the server's version of that item, downloaded from the server: only the files that differ from their own copy, kept for later joins. Their own copy stays as it is for single player and other servers.
description=[list]
description=[*]Server: set the sandbox option "Mod sync port" (a TCP port, 0 = off), restart, and open that TCP port in the firewall. Dedicated servers only; players without this mod join as before.
description=[*]Players: enable this mod. Before the first download from a server you are asked, with the items and their sizes; you can choose not to be asked again for that server.
description=[*]An item whose Java code (.jar) differs is not taken from the server: the join stops and names the item.
description=[*]Only for joins by address, not via Steam friends.
description=[/list]
description=
description=[h2]Network status icon[/h2]
description=In multiplayer, a signal icon in the bottom-left corner shows your connection to the server: the bars show the ping, a warning triangle shows packet loss. Hover it for ping, loss, traffic, how you are connected (UDP, Steam, or the TCP / KCP tunnel above) and debug numbers. Turn it off in Options > Mods.
description=
