version=1
title=ZombieBuddyKotlin
description=[h1]ZombieBuddyKotlin[/h1]
description=An unofficial Kotlin runtime for ZombieBuddy, made by Dont39. It is not made by ZombieBuddy's author.
description=It does nothing on its own. Mods written in Kotlin require it; subscribe to it along with them and enable it.
description=
description=[h2]What it does[/h2]
description=[list]
description=[*]The game ships an old Kotlin library (1.4.10) that it does not use itself. When the game starts, this mod puts Kotlin 2.4.21 in its place for all Java mods.
description=[*]Provides kotlinx-coroutines 1.11.0 and kotlinx-serialization-json 1.11.0.
description=[*]Checks that everything works and writes the result to console.txt: "[ZombieBuddyKotlin] ready: ..." or "[ZombieBuddyKotlin] not ready: ..." with the reason.
description=[*]Changes no game files and nothing in your saves.
description=[/list]
description=
description=[h2]Requirements[/h2]
description=[list]
description=[*][url=https://steamcommunity.com/sharedfiles/filedetails/?id=3619862853]ZombieBuddy[/url] 2.3.4 or newer with its Java loader installed (it asks you once to approve this mod's Java code).
description=[*]Project Zomboid 42.21
description=[/list]
description=Load order: ZombieBuddy, then this mod, then the mods that use it. Other mods that bring their own copy of Kotlin must load after this mod.
description=
description=[h2]For mod authors[/h2]
description=Require ZombieBuddyKotlin in your mod.info (require and loadModAfter), compile against the same Kotlin and kotlinx versions without bundling them, and check com.dont39.pz.zombiebuddykotlin.ZombieBuddyKotlin.isReady() before using anything that needs the current Kotlin.
